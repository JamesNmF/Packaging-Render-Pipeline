# 🎨 美术资产中枢 (Art Asset Hub) · v1.0 正式版

> **专为工业级美术资产、包装设计、三维视觉渲染与数字资产管理量身定制的一站式工作台中枢。**  
> 深度打通 **Adobe Illustrator / Photoshop 源文件** ➔ **工业级标准工程自动归档** ➔ **Blender 5.2 LTS 三维开工** ➔ **Beauty 通道渲染输出** ➔ **企业级 Excel 台账双向同步** ➔ **本地可视化全景画廊** 完整链路。

---

## 🌟 核心功能体系

### 1. 🖼️ 视觉资产看板 (Visual Asset Hub)
* **⚡ 零延迟瞬切架构 (Instant Turbo Engine)**：
  * **磁盘持久化缩略图池**：将 2K/4K 原始渲染大图在首次识别时压制为 15KB 微缩图存储于物理磁盘，后续加载耗时降至 **0.1ms**；
  * **30 卡片槽位复用池 (Widget Pooling)**：翻页与切换形态分类时 **0 控件销毁、0 从零重建**，分类切换耗时 `< 5ms`，像浏览本地网页般丝滑流畅；
  * **搜索输入防抖 (Debounce 200ms)**：实时打字过滤零粘滞。
* **📊 Excel 与本地硬盘智能双向融合**：
  * 支持无缝绑定并自动监听《产品列表.xlsx》；
  * 本地硬盘扫描结果与 Excel 台账智能比对，自动抓取最新的 Beauty / 成品高清渲染图作为封面。
* **🏷️ 4 大核心业务形态精准分类**：
  * `📦 包装`（默认工业兜底分类）、`🎁 套盒`、`🖼️ 海报`、`📑 物料`；
  * 支持 3 处随时手动修改（列表双击微调、批量应用、看板右键即时修改并回写 Excel）。
* **🌐 全景画廊导出**：
  * 一键导出单文件离线交互式 HTML 视觉画廊，支持直接在浏览器中全屏检视并点击直达本地目录。

---

### 2. 📥 设计源文件分拣与自动化开工 (Source Organizer & Pipeline Launcher)
* **🖱️ 资源管理器右键“发送到”一键唤起**：
  * 在 Windows 资源管理器中右键任意 `.ai` / `.psd` / `.pdf` 设计源文件，选择 `发送到 ➔ 一键创建美术项目并归档` 瞬间唤起工作台。
* **⚙️ 多维度自定义文件夹规则管理器 (Custom Folder Rules Manager)**：
  * 自由新建、编辑、克隆和删除文件夹归档规则；
  * 支持自定义子文件夹清单（如 5 阶段包装工程、海报 KV 创作流、极简打样流等）；
  * 支持自定义目录层级架构（`{客户}/{SKU}`、`{业务形态}/{客户}/{SKU}`、`{仅SKU}` 等）；
  * 规则内可视化绑定「源文件存入目录」、「3D工程生成目录」与「渲染图输出目录」，内置**所见即所得目录树实时预览**。
* **✨ 自动化母版工程派生与开工**：
  * 自动为新产品生成标准 `.blend` 工程并一键唤起 **Blender 5.2 LTS** 开工；
  * 归档成功后自动将新项目行追加写入 Excel 产品台账。

---

### 3. 🌿 温润工业石墨灰设计 (Studio Graphite Eye-Care Dark Mode)
* **工业级护眼调色**：
  * 对标 **Blender 5、Lightroom、Cinema 4D、Eagle** 经典专业调色体系；
  * 告别刺眼死黑与高反差荧光蓝，采用温润石墨灰（`#222429` ~ `#30333A`）与护眼米白文字（`#E2E4E8`）；
  * 柔和微灰底托设计，使白底与浅色渲染图在暗色工作台中自然融入，长时间工作眼睛极度舒适；
  * 顶部右上角支持一键自由切换浅色模式。

## 🚀 快速开始与使用指南

### 1. 启动方式
* **日常资产管理**：直接双击桌面带专属猫咪头像图标的 **`【美术资产中枢.exe】`**（或 `.lnk` 快捷方式）；
* **源文件快捷归档**：在 Windows 文件管理器中，右键任意设计源文件 ➔ `发送到` ➔ `一键创建美术项目并归档`。

### 2. 依赖环境
* **操作系统**：Windows 10 / 11 (64-bit)
* **三维渲染软件**：Blender 5.2 LTS (默认路径: `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`)
* **Python 环境** *(如从源码运行)*：Python 3.9+ (`Pillow`, `openpyxl`)
